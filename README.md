# 🌤 Telegram Weather Bot

Telegram-бот для получения актуальной информации о погоде в городах России с голосовым озвучиванием прогноза и автоматическим переводом текста.

## 📌 Описание

Многофункциональный Telegram-бот на базе Aiogram 3, который:
- Предоставляет детальную информацию о погоде в популярных городах России
- Озвучивает погодный прогноз голосом
- Переводит текстовые сообщения на английский язык
- Сохраняет отправленные изображения

Бот разработан для обучения работе с асинхронным программированием, Telegram Bot API через Aiogram 3 и интеграцией внешних сервисов.

## ✨ Возможности

### 🌍 Погода
- Актуальная информация о погоде в 8 городах России
- Подробные данные: температура, ощущается как, влажность, давление, скорость ветра
- Удобный выбор города через инлайн-кнопки (2 столбца)
- Голосовое озвучивание прогноза погоды (gTTS)
- Красивое форматирование с эмодзи 🌤

### 💬 Дополнительные функции
- Автоматический перевод текста на английский язык (Google Translate)
- Сохранение отправленных фотографий в папку `img/`
- Команды помощи и информации

## 🛠️ Технологии

- **Python 3.10+**
- **[Aiogram 3](https://docs.aiogram.dev/)** — асинхронный фреймворк для Telegram Bot API
- **[httpx](https://www.python-httpx.org/)** — асинхронные HTTP-запросы
- **[gTTS](https://pypi.org/project/gTTS/)** — преобразование текста в речь
- **[googletrans](https://pypi.org/project/googletrans/)** — перевод текста
- **[python-dotenv](https://pypi.org/project/python-dotenv/)** — управление переменными окружения
- **OpenWeatherMap API** — источник данных о погоде

## 📋 Требования

- Python 3.10 или выше
- Токен Telegram-бота (получить у [@BotFather](https://t.me/botfather))
- API-ключ OpenWeatherMap (регистрация на [openweathermap.org](https://openweathermap.org/api))

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/IIIPEK/Zerocoder_TG01.git
cd Zerocoder_TG01
```

### 2. Создание виртуального окружения

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux/macOS:**
```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Если файл `requirements.txt` отсутствует, установите вручную:
```bash
pip install aiogram httpx python-dotenv gTTS googletrans==4.0.0rc1
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта (используйте `example.env` как шаблон):

```env
TOKEN=ваш_токен_от_BotFather
API_KEY=ваш_ключ_от_OpenWeatherMap
API_URL=https://api.openweathermap.org/data/2.5/weather
GEO_URL=http://api.openweathermap.org/geo/1.0/direct
```

**Как получить токены:**
- **Telegram Bot Token**: напишите [@BotFather](https://t.me/botfather) в Telegram, создайте нового бота командой `/newbot`
- **OpenWeather API Key**: зарегистрируйтесь на [openweathermap.org](https://openweathermap.org/api) и создайте API-ключ

## ▶️ Запуск

```bash
python main.py
```

После запуска бот будет доступен в Telegram. Найдите его по имени, которое вы указали при создании.

## 🎮 Использование

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы с ботом |
| `/help` | Справка по доступным командам |
| `/weather` | Выбор города и получение погоды |

### Дополнительные функции

- **Отправьте текст** → бот автоматически переведёт его на английский
- **Отправьте фото** → бот сохранит его в папку `img/`

### Пример работы с погодой

1. Пользователь вводит `/weather`
2. Бот отправляет инлайн-кнопки с городами
3. Пользователь выбирает город (например, "Москва")
4. Бот показывает погоду с эмодзи и отправляет голосовое сообщение с прогнозом

**Формат ответа:**
```
📍 Москва
🌤 Ясно
🌡 Температура: -5°C (ощущается как -8°C)
💧 Влажность: 65%
🔽 Давление: 755.1 мм рт. ст.
💨 Ветер: 3.5 м/с
```

## 🐛 Решение проблем

**Бот не отвечает:**
- Проверьте правильность токена в `.env`
- Убедитесь, что бот запущен (`python main.py`)

**Ошибка при получении погоды:**
- Проверьте API-ключ OpenWeatherMap
- Убедитесь, что ключ активирован (может потребоваться до 2 часов)

**Проблемы с голосом:**
- Убедитесь, что установлена библиотека `gTTS`
- Проверьте наличие интернет-соединения
